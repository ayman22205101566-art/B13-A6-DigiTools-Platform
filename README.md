# Project name : DigiTools – Premium Digital Tools Platform
 
# Project Overview:
DigiTools is a modern web application designed to provide users with a curated collection of premium digital tools. The platform allows users to explore products, view pricing plans, and seamlessly add items to a cart for purchase. With a clean UI and responsive design, DigiTools ensures an efficient and user-friendly experience.

# Technologies Used :
React.js – For building dynamic and component-based UI
Tailwind CSS & DaisyUI – For modern, responsive styling
JavaScript (ES6+) – Core programming language
React-Toastify – For interactive toast notifications
JSON – For managing product data

# Key Features :
* Interactive Product Listing – Browse and explore premium digital tools with detailed descriptions
* Dynamic Cart System – Add products to cart and manage selections in real-time
* Modern UI/UX Design – Clean, responsive interface optimized for all devices
